# AtmosData — Weather Analytics Dashboard

A static, GitHub Pages-ready weather analytics dashboard.

## Files
- `index.html` — the dashboard website. It includes the sample dataset and supports loading a replacement CSV.
- `weather_analytics_50000_rows.csv` — the 50,000-row dataset used for the project.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **new public repository** (for example, `weather-analytics-dashboard`).
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html` and `weather_analytics_50000_rows.csv` from this folder. You can also upload this README.
4. Click **Commit changes**.
5. Open the repository's **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Choose branch **main** and folder **/(root)**, then click **Save**.
8. Wait a minute or two. The Pages section will show the published URL, usually:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Notes
- The website is a static dashboard; GitHub Pages hosts it, so no server is required.
- The dataset is synthetic for training/demo use and is not verified historical weather data.
- If you make the repository public, its files are publicly accessible. Do not upload private or sensitive data.
